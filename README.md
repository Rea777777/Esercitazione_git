# Hello World Java

Programma realizzato da: Francesco Rea e Fabi Lorenzo, classe 5E.

Questo progetto contiene un semplice programma Java che stampa la scritta "Hello World" sul terminale.

## Istruzioni per eseguire il programma

1. Aprire il terminale o il prompt dei comandi.
2. Posizionarsi nella cartella del progetto:
   ```bash
   cd C:\Users\studente4E\Desktop\5E_2026_2027\git
   ```
3. Compilare il file Java:
   ```bash
   javac Main.java
   ```
4. Eseguire il programma:
   ```bash
   java Main
   ```

L'esecuzione mostrerà a schermo:
```text
Hello World
```
